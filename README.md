# Autonomous Rover for Environment Mapping & Hazard Detection

Developed an autonomous rover integrating Raspberry Pi, ESP32, Raspberry Pi Camera, LiDAR, IMU, and MQ-2 gas sensor for real-time environmental monitoring and navigation. Implemented fire, smoke, and human detection using YOLOv8-Tiny and YOLOv11t for real-time hazard identification. Integrated LiDAR-based SLAM for environment mapping and localization, with RViz for real-time visualization of sensor data and the navigation environment. Exploring Reinforcement Learning (RL) techniques for autonomous navigation, intelligent decision-making, and optimized path planning in dynamic environments.

**Technologies:** Python, Raspberry Pi, ESP32, YOLOv8-Tiny, YOLOv11t, ROS, LiDAR, SLAM, RViz, OpenCV, Reinforcement Learning.
